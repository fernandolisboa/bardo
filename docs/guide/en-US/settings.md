# Settings

[Settings](bardo:go/settings/appearance) keeps what Bardo needs from you once, and how it looks. Each setting belongs to your Bardo profile and is saved as soon as you change it. [Show me Appearance](bardo:tour/appearance).

<a id="tabs"></a>
## The tabs

- **API keys**: one key per AI provider, kept in Windows Credential Manager. See [Your API keys](api-keys.md).
- **Networks**: the apps Bardo signs in to YouTube, Instagram and TikTok with. See [Network app credentials](app-credentials.md).
- **Publishing**: whether scheduled Reels go out while Bardo is closed. See [Publishing while Bardo is closed](background-agent.md).
- **Appearance**: the layout, the theme, the interface language and the guided tours, below.
- **Metrics**: when your posts' numbers sync by themselves. See [Syncing metrics](metrics-sync.md).

Each tab has its own tour: **Tour this screen** in the header, or Shift+F1, starts the one of the tab you are on.

<a id="layout"></a>
## Layout

The layout decides where every screen places its parts; the screens do the same things in every layout.

- **Workspace**: a sidebar by pillar, and cards with the details beside them.
- **Studio**: denser, with tabs across the top, tables with the details below, and a status bar.

Switching keeps the screen and the selection you are on, and a tour running at the time goes on in the new layout.

<a id="follow"></a>
## Following Windows

**Follow Windows** switches between a light and a dark theme of your choice when Windows switches between light and dark mode. Pick both beside it.

<a id="theme"></a>
## Theme

Ten interface themes, each checked for text contrast (the card says which WCAG level it meets):

| Kind | Themes |
| --- | --- |
| Light | Paper, Sand |
| Dark | Graphite, Slate |
| High contrast | High contrast light, High contrast dark |
| Terminal | Black Gold, Brass, Phosphor (dark), Phosphor Light |

The terminal themes draw everything in a monospace font with square corners. **Always the same theme** keeps the one you click.

<a id="language"></a>
## Interface language

The interface language sets Bardo's own words: the screens, the messages and this guide. On a new profile it follows Windows when Windows is in Portuguese, and is English otherwise. It does not change what Claude writes for a channel: that follows the channel's own language, set on [Channels](channels.md#market).

<a id="tours"></a>
## Guided tours

Every screen, stage and Settings tab has a tour of its own, which never starts by itself. **Offer tours on new screens** marks a screen's **Tour this screen** as **New** until you take or skip its tour; turned off, the mark never shows and the button stays. **Reset tours**, in the Guide menu, shows every tour as never seen and offers the welcome tour again.
