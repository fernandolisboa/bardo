# Keyboard shortcuts

Keys are named as they are printed on the keyboard. The Guide menu lists them too, under **Keyboard shortcuts**.

<a id="guide"></a>
## User guide

| Keys | Does |
| --- | --- |
| F1 | Opens the guide at the page for the screen you are on |
| Shift+F1 | Starts the tour of the project stage you are on, else of the screen, when it has one |
| ↑ ↓ | Moves through the contents or the search results while you type |
| Enter | Opens the highlighted page |
| Esc | Clears the search |

<a id="tour"></a>
## Guided tour

| Keys | Does |
| --- | --- |
| → or Enter | Next step |
| ← | Previous step |
| Esc | Closes the tour; Resume tour in the Guide brings you back |
| Tab, Shift+Tab | Moves between the card's buttons |

<a id="lists"></a>
## Lists

| Keys | Does |
| --- | --- |
| ↑ ↓ | Selects the previous or next item |
| Enter | Accepts what the selected item waits on |

<a id="editor"></a>
## Editor

| Keys | Does |
| --- | --- |
| Space | Play or pause |
| ← → | One frame back or forward |
| Home, End | Go to the start or the end |
| S | Split at the playhead |
| [ ] | Trim the selected clip's start or end to the playhead |
| Delete | Delete the selection |
| Alt+← Alt+→ | Move the selected clip one place, or audio one frame |
| Esc | Clear the selection |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |

<a id="suggestions"></a>
## Cut suggestions in the editor

| Keys | Does |
| --- | --- |
| Tab | Next suggestion |
| A | Accept the suggestion |
| R | Reject the suggestion |
