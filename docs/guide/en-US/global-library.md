# Global library

The **Global library** holds what every project can use: narrators, products and templates. [Show me](bardo:tour/library).

<a id="tabs"></a>
## Its tabs

The library has three tabs:

- **Narrators**: the voices and faces that speak your videos ([Narrators](personas.md)).
- **Products**: the products your ads show, with their briefs and pictures ([Products](products.md)).
- **Templates**: the instructions Claude writes from ([Templates](templates.md)).

<a id="libraries"></a>
## What each holds

Each tab is the same screen you know, with the same lists and forms: create, edit and archive items there as before.

<a id="projects"></a>
## Global for now

Today every narrator, product and template is global: the project's own Narrators, Products and Templates entries in the navigation open these same screens. A later version lets a project keep items of its own, with the global library shared by all of them.
