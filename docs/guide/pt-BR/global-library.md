# Biblioteca global

A **Biblioteca global** guarda o que todo projeto pode usar: narradores, produtos e modelos. [Mostre-me](bardo:tour/library).

<a id="tabs"></a>
## As abas

A biblioteca tem três abas:

- **Narradores**: as vozes e rostos que falam nos seus vídeos ([Narradores](personas.md)).
- **Produtos**: os produtos que seus anúncios mostram, com briefings e imagens ([Produtos](products.md)).
- **Modelos**: as instruções a partir das quais o Claude escreve ([Modelos](templates.md)).

<a id="libraries"></a>
## O que cada uma guarda

Cada aba é a mesma tela que você conhece, com as mesmas listas e formulários: crie, edite e arquive itens ali como antes.

<a id="projects"></a>
## Global por enquanto

Hoje todo narrador, produto e modelo é global: as entradas Narradores, Produtos e Modelos do projeto na navegação abrem estas mesmas telas. Uma versão futura deixa cada projeto ter itens próprios, com a biblioteca global compartilhada por todos.
