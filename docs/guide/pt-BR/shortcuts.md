# Atalhos de teclado

As teclas têm o nome que aparece impresso no teclado. O menu do Guia também lista os atalhos, em **Atalhos de teclado**.

<a id="guide"></a>
## Guia do usuário

| Teclas | Faz |
| --- | --- |
| F1 | Abre o guia na página da tela em que você está |
| Shift+F1 | Começa o tour da etapa do projeto em que você está, ou senão da tela, quando ela tem um |
| ↑ ↓ | Percorre o sumário ou os resultados da busca enquanto você digita |
| Enter | Abre a página destacada |
| Esc | Limpa a busca |

<a id="tour"></a>
## Tour guiado

| Teclas | Faz |
| --- | --- |
| → ou Enter | Próximo passo |
| ← | Passo anterior |
| Esc | Fecha o tour; Retomar tour, no Guia, traz você de volta |
| Tab, Shift+Tab | Passa pelos botões do cartão |

<a id="lists"></a>
## Listas

| Teclas | Faz |
| --- | --- |
| ↑ ↓ | Seleciona o item anterior ou o próximo |
| Enter | Aceita o que o item selecionado está esperando |

<a id="editor"></a>
## Editor

| Teclas | Faz |
| --- | --- |
| Space | Reproduz ou pausa |
| ← → | Um quadro para trás ou para a frente |
| Home, End | Vai para o início ou para o fim |
| S | Divide no cursor |
| [ ] | Apara o início ou o fim do clipe selecionado até o cursor |
| Delete | Apaga a seleção |
| Alt+← Alt+→ | Move o clipe selecionado uma posição, ou o áudio um quadro |
| Esc | Limpa a seleção |
| Ctrl+Z | Desfaz |
| Ctrl+Y ou Ctrl+Shift+Z | Refaz |

<a id="suggestions"></a>
## Sugestões de corte no editor

| Teclas | Faz |
| --- | --- |
| Tab | Próxima sugestão |
| A | Aceita a sugestão |
| R | Rejeita a sugestão |
