# Test photos of the product-cutout spike (issue #277)

Twenty-five photos from Wikimedia Commons, each released by its author under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (no rights reserved), which allows them here. Each file is Commons' own rendition of the original at a standard width (960, 1280 or 1920 pixels), scaled to 1280 pixels on its longer side and saved as JPEG at quality 88; nothing else was changed. The last column is the SHA-1 Commons gives for the original file.

A name on a label, a box or a device in a photo is its owner's; the photos are here to test cutting an object out of a picture, and say nothing about those products.
